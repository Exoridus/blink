# ExoJS-Upgrade 0.8.3 → 0.15.2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Blink von `@codexo/exojs@0.8.3` auf `@codexo/exojs@0.15.2` + `@codexo/exojs-audio-fx@0.15.2` migrieren, obsoleten Eigenbau entfernen, Audio-Verhalten messbar verifizieren.

**Architecture:** Big-Bang-Upgrade auf einem Feature-Branch mit vorher aufgenommener Audio-Baseline (deterministisches Probe-Master-WAV). Migration in fester Reihenfolge: WIP-Commit → Baseline → Dependency-Bump → vendored Shader-Util → RenderService → Typ-Umstellung → AudioService → Statistics/Shim → Verifikation → Vergleichsmessung/Kalibrierung.

**Tech Stack:** TypeScript 6, Vite 8, Vitest 2, ExoJS 0.15.2 (WebGL2-Backend), Web Audio API.

## Global Constraints

- Zielversionen exakt: `@codexo/exojs@^0.15.2`, `@codexo/exojs-audio-fx@^0.15.2` (lockstep, beide zusammen bumpen).
- Alle Arbeit auf Branch `exojs-0.15-upgrade`; `master` bleibt bis zum Abschluss unberührt.
- Zwischen-Commits auf dem Branch dürfen rot sein (Dependency-Bump bricht alles auf einmal); jede Task endet mit dem angegebenen Prüf-Kommando. Ab Task 8 muss alles grün sein.
- Prüf-Kommandos: `npm run ts-check`, `npm run lint`, `npm test` (Vitest run), `npm run dev` (Smoke).
- Die Blink-Spektrum-Pipeline (`BlinkAudioSurfaces`, `BlinkAudioPackers`, `BlinkSpectrumGenerators`, `BlinkAudioTextureRuntime`-Logik, 12→4-Band-Builder) wird architektonisch NICHT verändert — nur Typ-Importe. Konstanten (z. B. `SCALE_FACTOR`) ändern sich ausschließlich in Task 10 nach Messung.
- Verifizierte 0.15.2-API-Fakten (Quelle: installierte `.d.ts` in Scratchpad-Probe, 2026-07-06):
  - `getAudioContext` wird WEITERHIN aus `@codexo/exojs` exportiert (Core-Audio-Barrel).
  - `AudioAnalyser`, `BeatDetector` kommen aus `@codexo/exojs-audio-fx`; Methoden-/Property-Oberfläche, die Blink nutzt (`source`, `frequencyBinCount`, `getSpectrumFloat`, `getSpectrumLogFloat`, `getWaveformFloat`, `getRms`, `getBandEnergy`, `tempo`, `beatPhase`, `onsetStrength`, `onBeat`, `onDownbeat`, `BeatInfo.energy`, `BeatInfo.beatInBar`) ist unverändert vorhanden.
  - `MeshShader` und Typ `MeshShaderUniformValue` existieren NICHT mehr → `MeshMaterial` (+ `MeshMaterial.from(vertex, fragment, { uniforms })`) und Typ `UniformValue` (Root-Export).
  - `upgradeFragmentShaderToGl300` ist NICHT mehr exportiert (intern seit 0.14, `exports`-Map blockiert Deep-Imports) → wird nach Blink vendored (Task 4).
  - `Scene.draw` erhält `RenderingContext` (nicht `RenderBackend`); `Scene.update` erhält `Time` (`.seconds` existiert weiter).
  - `ApplicationOptions` gruppiert: `{ clearColor?, backend?: { type: 'webgl2' }, canvas?: { element?, width?, height?, pixelRatio?, tabIndex?, ... }, rendering?: { webglAttributes? }, ... }`. `app.canvas: HTMLCanvasElement` (readonly) existiert; `app.start(scene)`, `app.stop()`, `app.resize(w, h)` existieren.
  - WICHTIG: seit 0.14 gibt es automatisches DPR-Handling — `app.canvas.width` ist Backing-Store-Größe. `canvas.pixelRatio: 1` pinnt das alte Verhalten (RESOLUTION-Uniform bleibt identisch zu 0.8.3).
  - `Text`-Optionen: `fillColor?: Color`, `outlineColor?: Color`, `outlineWidth?: number` (statt `fill`/`stroke`/`strokeThickness` als Strings); `padding` existiert nicht mehr; `anchor` (normalisiert, auf `SceneNode`) existiert weiter; `fontWeight` ist `'100'…'900'|'normal'|'bold'`-Literal.
  - `DataTexture`: `{ width, height, format, data?, samplerOptions? }`, `commit()`/`commitRect()`/`destroy()` existieren weiter — Blinks Nutzung ist bereits kompatibel, nur der Uniform-Typ ändert sich.
  - `@codexo/exojs/debug` liefert eigene Typen (`DebugOverlay` mit `layers.performance`) → Blinks Shim ist obsolet.
  - `Color`-Konstruktor: `(r?, g?, b?, a?)` mit RGB 0–255.

```ts
/**
 * Upgrades legacy GLSL ES 1.00 fragment shader source to GLSL ES 3.00.
 *
 * Vendored from ExoJS (own engine, internal since 0.14 — the function is no
 * longer part of the public package surface). Idempotent: calling twice
 * returns the same source.
 *
 * NOT supported (produce GLSL compile errors the effect author must port
 * manually): gl_FragData[N], texture2DLod/textureCubeLod, gl_FragDepthEXT.
 */
export function upgradeFragmentShaderToGl300(source: string): string {
    if (/^\s*#version\s+300\s+es/.test(source)) {
        return source;
    }

    const stripped = source.replace(/^\s*#version[^\n]*\n/, '');

    const transformed = stripped
        .replaceAll(/\bgl_FragColor\b/g, 'fragColor')
        .replaceAll(/\btexture2D(?=\s*\()/g, 'texture')
        .replaceAll(/\btextureCube(?=\s*\()/g, 'texture')
        .replaceAll(/\btexture2DProj(?=\s*\()/g, 'textureProj')
        .replaceAll(/\bvarying\b/g, 'in');

    // Precision MUST precede `out vec4 fragColor;` (GLSL ES 3.00 requires
    // precision before any float-typed declaration).
    const header = '#version 300 es\nprecision highp float;\nout vec4 fragColor;\n';

    return header + transformed;
}
```
