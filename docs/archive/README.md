# Archived documentation

Everything below this directory is historical. It records how earlier
implementation phases were designed and planned, but it is no longer an active
source of truth. Relative paths inside the archived documents refer to the
repository layout at the time they were written.

| Directory | Period | Status |
| --- | --- | --- |
| `blinkfx-pre-r2/` | May - July 2026 | BlinkFX concept, July 9 manifest spec, multipass runtime design and plan. Superseded by the BlinkFX v1 Final Candidate R2 line. |
| `exojs-0.15-upgrade/` | July 2026 | Design and plan for the ExoJS 0.8.3 to 0.15.2 upgrade. Completed. |

The current BlinkFX target design is described in `AGENTS.md`. Audio research
material (spectrum pipeline ground truth, probe baselines) lives in
`docs/research/audio/`.
