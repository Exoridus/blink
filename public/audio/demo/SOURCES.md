# Demo recording sources

These recordings retain their CC0-1.0 dedication independently of the Blink software license. Source pages and the original archive notice were checked before inclusion. Files are copied unchanged; only distributed filenames differ.

- **Super Action Chiptunes - Stage 6** by Juhani Junkala: [author publication](https://opengameart.org/content/12-music-loops), CC0-1.0. Original file: `215 [Super Action Chiptunes] bgm_stage_6.ogg`.
- **Friendly Talk on a Robotic Battlefield** by illin: [author publication](https://opengameart.org/content/friendly-talk-on-a-robotic-battlefield-looped), CC0-1.0. Original file: `Friendly Talk On a Robotic Battlefield_0.ogg`.
- **The 9th Circle** by Joth: [author publication](https://opengameart.org/content/the-9th-circle), CC0-1.0. Original file: `The 9th Circle V2.mp3`.
- **JRPG2 Piano** by Joth: [author publication](https://opengameart.org/content/jrpg2-piano), CC0-1.0. Original file: `JRPG2 Piano.mp3`.
- **Mandatory Overtime** by Joth: [author publication](https://opengameart.org/content/mandatory-overtime), CC0-1.0. Original file: `Mandatory Overtime.mp3`.
- **Chiptune Adventures - Stage 1** by Juhani Junkala: [author publication](https://opengameart.org/content/4-chiptunes-adventure), CC0-1.0. Original file: `Juhani Junkala [Chiptune Adventures] 1. Stage 1.ogg`.
- **Chiptune Adventures - Stage 2** by Juhani Junkala: [author publication](https://opengameart.org/content/4-chiptunes-adventure), CC0-1.0. Original file: `Juhani Junkala [Chiptune Adventures] 2. Stage 2.ogg`.

Track and archive SHA-256 hashes, download URLs and byte sizes are recorded in manifest.json. SOURCE-INFO.txt is the original notice for the two Chiptune Adventures recordings, not a notice from the other artists. LICENSE-CC0.txt supplies the common license text. Menu Music is not included because its author reports using Apple loops and redistribution rights need separate review.
